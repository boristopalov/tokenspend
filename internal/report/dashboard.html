Cache economics

In an agent loop most input is re-read history, so the cache decides the bill. A cache-miss request here is one with ≥ 20K input tokens where less than half came from cache: those pay full or write price for the whole context.

Per model

Context attribution

Input cost assigned to the transcript content that caused it. Every request re-reads its whole context, so each tool result, prompt or file read is charged a share of every later request that carried it, until compaction drops it. Item sizes are estimated from their text, then corrected per thread by fitting actual input ≈ slope × estimated size + intercept over the thread's requests: the slope adjusts for the model's tokenizer, and the intercept, which is context present in every request but never logged (a system prompt or tool schemas the transcript doesn't record), is unattributed. Each request's shares add up to its real input cost. The date filter here selects content by the day it entered context.

Most expensive single items

Sessions

Claude Code: reported vs. computed

Claude Code keeps a running cost counter per session (cost-state) that includes calls never written to the transcript. Where the counter's tokens exceed what transcripts and OTel explain, the gap appears above as background / unlogged (cost-state gap). A counter below the transcript usually means the session was resumed: the counter only covers the last process.

Codex plan usage

On a ChatGPT plan, Codex spend is rate-limit usage rather than dollars. Percent of each window used, last reading per hour.

Method and caveats

  • All dollar figures are API list-price equivalents. On a subscription (Claude Max, ChatGPT Plus) you are not billed per token, but these numbers still rank where usage goes.
  • Claude Code transcripts repeat one API response over several lines; usage is counted once per requestId. Codex usage comes from token_usage_record (one per response, deduplicated by response_id). Pi records its own USD cost, which is used as-is.
  • OTel data (from tokenspend otel) adds requests no transcript recorded and supplies Claude Code's query_source for requests the transcript doesn't label.
  • Cache-write TTL is unknown for the cost-state gap; it is priced as 5-minute writes.
